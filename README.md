# Mapa de Mesas · M&D

Kanban de mesas do casamento (17×10 lugares, expansível). Lista de convidados por upload/colar, arrastar ou toque no celular. Dados ficam no `localStorage` do navegador.

## Uso local

Abra `index.html` ou:

```bash
python3 -m http.server 8080
```

## Exportar / sincronizar

Use **Exportar → Backup (.json)** e **Restaurar** para levar o mapa entre aparelhos.
